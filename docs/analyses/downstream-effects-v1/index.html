Inspect how a local intervention reaches the output.

Every trial attenuates 32 selected gate activations at one token, then runs the actual remaining model. Selections and gains were frozen on calibration data. The observer retains source frames and total downstream effects.

Full top-group removal produces greater output change, but after calibration matching the top groups exceed random groups in only 1 of 18 comparisons. Holdout local RMS ratios range from 0.681 to 1.152. This is evidence about perturbation sensitivity, not a semantic category or an isolated circuit path.

Scope and source evidence

Native FP32 evaluation; FP64 metric reductions; 50,304 vocabulary entries. The same original token sequence is used throughout. Future-token effects describe teacher-forced propagation, not generated continuations. Final-layer edits cannot affect another token because no subsequent attention remains.

All 1,152 local/causal controls and six exact zero-gain controls passed. The main study used 1,170 backbone forwards; a separate seven-forward audit retained six edited full-vocabulary logit vectors. No training occurred.
